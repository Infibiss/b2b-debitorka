# Mandato упрощение интерфейса и юридическое дело по договору

База: main `0c859378b3513f94d908b35c6b21d9ac1dbd6285`. Материалы юристов остаются локально в lawyers и не входят в Git или Docker context.

## Поведение

Юридическое дело включает явно выбранные счета одного существующего договора. Связь уникальна по счёту и организации. Общий остаток, пошлина и расчёт требований учитывают каждый счёт; фикс пакета начисляется один раз на дело. Старые дела, финансовые записи и бинарные DOCX не переписываются. Добавляются таблицы legal_case_invoices и legal_evidence_invoices.

Доказательство имеет явное покрытие счетов. Комплектность одного счёта не переносится на остальные. Изменение любого остатка делает прежний документ устаревшим. Актуальность проверяется по каждому счёту; равные разнонаправленные изменения не скрывают устаревшую разбивку. Начальные оплаты для санкций задаются по каждому счёту. Общий лимит неустойки по нескольким счетам отклоняется с требованием отдельного расчёта.

Отмена приказа требует определения суда и блокирует повторный приказ/исполнение по нему. Проверен дальнейший путь: иск, проверка юристом, подача, решение, исполнительный лист и передача в банк. Это учёт ручных действий, а не автоматическая подача. Ответственный юрист, полномочия и срок проверки задаются в деле; отдельный внешний пользователь с ограниченным доступом пока не вводится.

В интерфейсе убраны повторная шапка рабочего пространства, футер-лозунги, нижние дубль-кнопки работы и аудита, дублирующий переход из настроек и лишние пояснения. Восстановление пароля соответствует странице входа, поддержка открывается прямой ссылкой. Настройки разделены на полноширинные секции; документы — на загрузку/архив и OCR. Единые загрузки показывают русскую кнопку и имя файла. Цвета, select-стрелки и формы закреплены в docs/design-system.md и общем CSS. Неподключённые каналы и непроверенные результаты не обозначаются успехом.

## Размещение

GitHub deployment остаётся opt-in: прежнее решение владельца разрешает SSH только с одного операторского IP. Для существующего mandato.ru подготовлен --public-url: существующие Nginx и сертификаты сохраняются, URL/IP проверяются до остановки приложения. Новые домены, сертификаты, сетевые правила и облачные ресурсы автоматически не создаются.

Первоначальный timeout SSH оказался связан со сменой адреса выхода VPN. Прежний операторский /32 заменён текущим операторским /32, остальные правила группы безопасности сохранены. Вход по проверенному host key восстановлен. Свежая резервная копия PostgreSQL сохранена на Mac с правами 0600 и проверкой SHA256; перед обновлением записаны закрытые контрольные суммы восьми финансовых/документных таблиц.
