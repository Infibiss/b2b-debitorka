# Маленькая Yandex VM для AgentPay

Проверено 24.10.2026 по официальным тарифам региона Россия, RUB с НДС. Исследование само ресурсов не создавало; позднее владелец согласовал VM с пределом 2 000 ₽/месяц. Фактическое размещение описано в протоколе выпуска.

Для первого работающего экземпляра выбран ориентир **2 vCPU Intel Ice Lake, гарантированная доля 20%, 2 ГБ RAM, SSD 30 ГБ, один статический IPv4**. На VM только app + PostgreSQL + Nginx. Langfuse остаётся опциональным локальным инструментом. GPU для внешнего Yandex LLM API не нужен. 20% означает гарантированную долю времени физического ядра, поэтому это конфигурация малой нагрузки, без обещания высокой производительности. [Уровни CPU](https://yandex.cloud/ru/docs/compute/concepts/performance-levels).

## Остановка и освобождение

Остановка убирает оплату CPU/RAM, но диск, снимки и образы продолжают оплачиваться до удаления. Статический IP у остановленной VM стоит уже 0,6039 ₽/ч (434,81 ₽ за 30 дней): обычная цена + резервирование неактивного адреса. Динамический адрес освобождается при остановке и меняется при следующем старте; reboot сохраняет его. Поэтому для постоянной ссылки и IP-сертификата подходит статический адрес. Для полного прекращения затрат надо отдельно проверить ненужные диски/снимки/IP/объекты. [Compute billing](https://yandex.cloud/ru/docs/compute/pricing), [адреса](https://yandex.cloud/ru/docs/vpc/concepts/address).

## Резервные копии

Частный STANDARD bucket с `pg_dump`-архивами: первый 1 ГБ хранения, первые 10 000 write/list и 100 000 read/head операций в месяц бесплатны. Далее STANDARD — 2,376 ₽/ГБ·месяц; 10 ГБ среднего объёма стоят около **21,38 ₽/месяц** после free tier. Для короткой ротации не выбирать ICE: минимальный оплачиваемый срок — год. Установить lifecycle/лимит размера, запретить публичный доступ, дать служебной учётной записи права только на backup bucket. [Storage pricing](https://yandex.cloud/ru/docs/storage/pricing), [доступ](https://yandex.cloud/ru/docs/storage/security/overview).

Рецепт в репозитории делает ежедневный частный локальный архив, ротацию 14 дней и дополнительный backup перед обновлением. Off-VM bucket/upload — отдельный ещё не включённый шаг: локальная копия на том же диске не спасает от потери VM/диска. До эксплуатации реальных финансовых данных подключить независимое хранение и проверить restore.

## Сеть и HTTPS без домена

Создать пользовательскую security group: TCP 22 только с адреса оператора; 80/443 из интернета. PostgreSQL, app port и службы Langfuse не публиковать. Default SG разрешает весь входящий трафик, поэтому её недостаточно. Первые 100 ГБ исходящего трафика в месяц бесплатны; TCP 25 блокируется платформой, для SMTP нужен поддержанный защищённый порт провайдера. [Security groups](https://yandex.cloud/ru/docs/vpc/concepts/security-groups), [VPC addresses](https://yandex.cloud/ru/docs/vpc/concepts/address).

Let's Encrypt выдаёт доверенные IP-сертификаты сроком 160 часов. Certbot ≥5.4 поддерживает `--ip-address` с webroot и профилем `shortlived`; необходимы автоматическое продление и reload сервера. В рецепте закреплён Certbot 5.8.0 и timer дважды в день. [Официальная инструкция](https://letsencrypt.org/2026/03/11/shorter-certs-certbot/), [GA IP-сертификатов](https://letsencrypt.org/2026/01/15/6day-and-ip-general-availability/).

Бюджет Yandex Billing отправляет уведомления, сам по себе не останавливает потребление. Настроить пороги, например 1 000/1 700/2 000 ₽, и отдельно контролировать токены LLM. [Бюджеты](https://yandex.cloud/ru/docs/billing/concepts/budget).
