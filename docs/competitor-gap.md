# Mandato и ЮРРОБОТ: сверка функций

Источники: база знаний ЮРРОБОТ, полное руководство v2.10.43 (1743 страницы, 08.11.2026) и обзорное видео. Видео старое, при расхождении приоритет у руководства.

ЮРРОБОТ в основном заточен под ЖКХ и взыскание с граждан. Mandato работает с B2B-долгами, поэтому Росреестр, долевые собственники, домовые книги, мировые судьи и ГРЗ не переносим.

| Раздел | Статус | Что есть в Mandato | Чего нет |
| --- | --- | --- | --- |
| 1. Регистрация | Есть | Почта, пароль, сброс, отдельное согласие | Вход по телефону, капча |
| 2. Организации | Есть | Реквизиты, доверенность, команда, роли, несколько организаций в одном кабинете, сводка по ним | Филиалы по КПП |
| 3. Обмен данными | Частично | Реестр CSV/Excel, выгрузка 1С, выписка банка, настройка колонок | Постоянная интеграция с 1С и CRM, публичный API-ключ |
| 4.1 Досудебное | Есть | Этапы, статусы и «Мой статус», мультифильтр, массовые действия, пауза, архив, три уровня писем по сумме, контроль обещаний, расписание, пороги по каналам, расчёт 395 ГК, соглашение, акт сверки, гарантийное письмо | Голосовой робот и SMS работают только после подключения провайдера; ЭЗП Почты России |
| 4.2 Судебное | Частично | Выбор приказ/иск, госпошлина и реестр на оплату, приказ, иск, иск после отмены, 9 ходатайств, журнал дела, автопередача в суд по согласию клиента | Подача через «Мой арбитр» и КЭП, автополучение статусов из картотеки |
| 4.3 Исполнительное | Частично | Заявления в банк, ФССП, ФНС, жалоба, арест, розыск, отзыв, повторное предъявление, учёт производств и счетов, намерение о банкротстве | Отправка через Госуслуги, автополучение статусов ФССП |
| 5. Конструктор документов | Есть | 33 шаблона, правка текста, свои документы на любой этап, переменные | Импорт DOCX как шаблона |
| 6. Конструктор отчётов | Есть | Свой отчёт по колонкам и этапу, старение долга, реестр пошлин, отправка по расписанию сотрудникам | Выгрузка во внешние системы |
| 7. Рабочий стол | Есть | Обзор и свои панели: показатель, разбивка, динамика, общие и личные, по одной или всем организациям | Выбор цвета плиток |
| 8. ЭДО | Нет | Документы хранятся в карточке | Диадок, СБИС, Госпочта |
| 9. Распознавание | Есть | Судебные приказы, определения, решения, листы и платёжные поручения из PDF; привязка к должнику; следующий шаг после подтверждения; сканы через подключённое OCR | Распознавание штрих-кодов суда |
| 10. Панель управления | Есть | Тариф, смена пароля, данные аккаунта | Партнёрская ссылка, журнал обновлений |
| 11. Функции | См. выше | | |
| 12–13. Справка | Частично | Подсказки в кабинете | База знаний для клиентов |

Что Mandato делает лучше: финансирование долга до оплаты, разбор ответов должника агентом, готовность документов к суду, экономика суда по каждому долгу, предупреждение о давности.

## Порядок доработки

1. Отправка в «Мой арбитр» и статусы из картотеки арбитражных дел.
2. ЭДО и электронные заказные письма.
