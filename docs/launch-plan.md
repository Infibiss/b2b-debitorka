# План запуска Mandato

Обновлено 08.11.2026.

## Сейчас работает

Реестр должников и три этапа взыскания, расчёт долга, процентов и пошлины, претензии и судебные документы в DOCX, автоматические письма при подключённой почте, разбор ответов, сверка по выписке, заявки на финансирование, отчёты, русский и английский интерфейс.

## Нужно от основателей

| № | Что | Зачем |
| --- | --- | --- |
| 1 | Разрешить SSH для деплоя: правило `operator-ssh` в группе `agentpay-pilot` | Новая версия ещё не на сервере |
| 2 | Реквизиты ИП или ООО: наименование, ИНН, ОГРН, адрес, банк | Нужны по 152-ФЗ и для счетов. Сейчас на сайте указано, что они есть в договоре |
| 3 | Договор-оферта, договор с юристом, форма доверенности | Юрист должен проверить условия и шаблоны документов |
| 4 | Решение по тарифам | Цены на сайте теперь отличаются от презентации для Газпромбанка |
| 5 | Проверка финансовой модели с экспертом и бухгалтером | Налоги и доля банка пока гипотезы |
| 6 | Основной юрист-партнёр для судебной стадии | Статус «На проверке у юриста» требует исполнителя |
| 7 | Финансовый партнёр: банк или факторинговая компания | Заявки пока обрабатывает оператор вручную |

## Что подключить

| Подключение | Что нужно | Состояние |
| --- | --- | --- |
| SMTP и IMAP клиента | Адрес и доступы к почте | Код готов |
| Банк: выписка по API | Доступ Т-Банка или другого банка | Файл выписки работает, API готов для Т-Банка |
| Приём оплаты подписки | Эквайринг или счета | Сейчас счёт выставляет оператор |
| Сервисная почта | `AUTH_SMTP_*`, `SUPPORT_EMAIL` | Нужны настройки |
| DaData | Ключ API | Код готов |
| Голосовые звонки и SMS | Оператор связи, SIP, SpeechKit | Канал отмечен «Подключается по заявке» |
| Почта России, заказные письма | Договор и токен | Не сделано |
| Подача в суд, ФССП, Госуслуги, КЭП и МЧД | Подпись, доступы и отдельная разработка | Не сделано, подача вручную |

## Порядок работ

1. Деплой текущей версии.
2. Реквизиты, договор, проверка шаблонов юристом.
3. Первые 3–5 реальных портфелей: замер доли оплат до суда и трудозатрат.
4. Обновление финансовой модели на этих данных.
5. Интерфейс по вашему UI-промпту.
6. Партнёр по финансированию и банковский API.
7. Почта России, КЭП, подача в суд.
