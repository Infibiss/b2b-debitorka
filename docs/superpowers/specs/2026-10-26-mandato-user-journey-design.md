# Mandato: понятный вход и ежедневная работа

Основание: пользователь просит сразу исправить перечисленные проблемы и затем показать весь путь в Chrome. Повторное согласование этих же правок не требуется.

Главная объясняет результат (регулярные напоминания, общий контекст договора и очередь вопросов человеку). Показатели конкурентов служат исследованием подачи; проценты их клиентов не становятся обещаниями Mandato. Калькулятор объясняет только проценты по кредиту при заданной сумме и задержке. FAQ и завершающий блок получают цельную адаптивную композицию.

В шапке рабочего пространства постоянно доступны шесть операций: счета, оплаты и сверка, переписка, документы, прогноз и условия, претензии и суд. Разбор входящего ответа доступен из переписки и из карточки дела, без отдельного седьмого пункта. Возможности не удаляются.

Кнопка «Обучение» слева запускает общий обзор четырёх разделов. Кнопка «Помощь по разделу» в шапке открывает текущий урок. Подсказки справа внизу, с возвратом и закрытием, без блокирующего фона. В уроке по работе подсвечивается карточка дела, а при пустом портфеле — кнопки загрузки.

Профиль внизу содержит компанию, имя и роль. По нажатию доступны настройки и выход. Памятка о правилах закрывается с сохранением выбора для пользователя. Финансовые и юридические правила сервера не меняются.

Проверка: браузерные сценарии настольного и мобильного интерфейса, клавиатура профиля, повтор обучения, пустой и заполненный портфель, расчёт процентов, отсутствие горизонтального переполнения. Перед выпуском — полный набор проверок, CI и ручной деплой с резервной копией. После выпуска — регистрация и загрузка синтетического портфеля через Chrome, без писем или звонков третьим лицам.
