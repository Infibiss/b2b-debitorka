# Mandato: единый рабочий кабинет

> Реализация в текущей сессии по прямому поручению пользователя; проверки между независимыми областями обязательны.

**Цель:** убрать промежуточные учебные сценарии, перенести управление данными в настройки и привести весь кабинет к одному визуальному контракту.

**Архитектура:** существующие API и права организации сохраняются. Настройки данных — отдельный компонент вне формы реквизитов. Обзор каждого раздела запускается напрямую в текущем контексте. Голосовая работа использует проверяемую границу подключения; отсутствие телефонии не создаёт вымышленный звонок. Публичная часть получает навигационный и финальный CTA.

**Стек:** React / TypeScript / CSS, FastAPI, PostgreSQL и SQLite, Playwright / pytest.

## Аудит и направление Unslop

- Знак sidebar не имеет desktop-размера и вытесняет название; нужен mark32 / word25 с полной видимостью.
- Общие карточки отличаются фоном, отступами и размерами текста; нужен белый surface, body16 / control14 / caption12 / panel20 / page28–32.
- Накопленные каскадные переопределения создают повторную рамку поиска и два знака помощи; исправить исходные семейства правил.
- Помощь открывает лишний диалог с browser voice simulation; запускать контекстный обзор напрямую.
- Удаление организации находится вне рабочего кабинета; перенести в настройки с сохранением подтверждения, полномочий и номера запроса.
- Главная заканчивается информацией о подключениях без действия; финальный блок напоминает пользу и ведёт в пробный период.

Продукт — работа бухгалтера и юриста с долгом до оплаты. Характер — спокойный, точный, деловой. Мир — документы, договоры, финансовые записи. Выделение — текущий этап и следующее действие. Сквозной элемент — последовательность этапов дела. Сохранить Manrope, ouroboros и зелёный фирменный акцент. Применяется Unslop by Damir Sokolovsky (CC BY 4.0), только рекомендации; встроенные скрипты не запускать.
