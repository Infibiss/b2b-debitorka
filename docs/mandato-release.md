# Mandato: портфельный выпуск 24.10.2026

Этот документ описывает расширение после `ed8e65e`; прежние протоколы сохранены как история. Проверки и публикация дополняются фактическими результатами ниже.

## Реализованный маршрут

1. Загрузить CSV-реестр или CSV/XLSX ОСВ/акт; сверить и согласовать исходные суммы. Остаток ОСВ без документов не создаёт обязательство.
2. Запустить «Аудит»: текущий остаток, просрочка, расхождения с датированным источником, документы, статус регистрации, обещания/транши, юридические контрольные даты, расходы и следующий шаг. Версия аудита неизменяема; после изменений она устаревает.
3. Зарегистрировать реквизиты или закрытое вложение договора, исполнения и условий оплаты; назначить контрольную дату с основанием и зафиксировать результат проверки. Полная оплата не отменяет самостоятельный процессуальный срок.
4. Прочитать источник через настроенный адаптер либо загрузить банковскую выписку. Подтвердить выбранные строки, затем отдельно распределить денежный источник. Дубликат файла/API/ручной записи не создаёт дополнительные деньги; разные похожие платежи требуют подтверждения и основания.
5. Проверить регистрацию по точному ИНН через DaData. Результат содержит источник, время запроса и охват. Суды, ФССП и полный реестр банкротств автоматически не проверяются.
6. В разделе «Поступления и условия» посмотреть сценарии на 7/30/60 дней при достаточной истории банковских распределений. При нехватке истории результат отсутствует, а не равен выдуманному прогнозу.
7. Включить явные правила переговоров и зарегистрировать проверенные условия. LangGraph повторно проверяет полномочия, лимиты и финансовое состояние перед исполнением внутреннего действия. Шесть видов: обещание, рассрочка, скидка, спор, сообщение об оплате, запрос документов. Скидка не списывает долг; сообщение об оплате не подтверждает деньги.
8. При необходимости выдать партнёру отзываемый доступ к агрегированному отчёту на срок до суток. Это технический API, не действующее банковское встраивание или кредитное решение.

| Диадок | Реальный адаптер чтения метаданных и контрактные тесты. | Ящик организации, токен, проверка тарифа/прав API и клиентского документа. Подпись и отправка не реализованы. |

Бесплатность конкретного поиска по ИНН проверена по [официальному методу](https://dadata.ru/api/find-party/) и [тарифам](https://dadata.ru/pricing/): до 10 000 запросов в сутки. Платная стандартизация — отдельный API, он не используется. Не оформлялись платные подписки, дополнительные VM, GPU или Colab.

## ML и автономность

CPU-пайплайн регуляризованной логистической модели готов для авторизованного point-in-time JSONL: проверка контракта, хронологические train/validation/test с purge, train-only нормализация, baseline/Brier/калибровка, ограниченный JSON-артефакт. [Контракт](payment-model.md). Настоящего клиентского датасета пока нет, поэтому обученного и опубликованного скоринга нет. Синтетические тесты не являются оценкой качества на клиентах.

Прогноз сейчас — эмпирический сценарий по наблюдаемым банковским когортам. Автономность — только принятие проверенных структурированных условий в явно включённых пределах. Внешняя почта/телефония, аутентификация должника и полноценные самостоятельные переговоры не подключены. Звонящий агент, банковский SSO, подача в суд и сторонние платные реестры в этот выпуск не входят.

## Проверка и публикация

Локально подтверждено:

- Полная серверная регрессия с настоящей disposable PostgreSQL: **420 passed, 1 skipped**, 44,70 с. Пропуск — только явный opt-in живого платного LLM-canary; его в этом бесплатном выпуске не запускали.
- Полный Chromium desktop + Pixel 7: **38 passed**, 1,6 мин. Внешние источники в контрактных браузерных ветках подменены явно; деньги/документы/согласования работают через настоящее локальное API.
- После добавления в карточку явного охвата реестров и суммы пошлины: дополнительные **6/6** портфельных браузерных проверок на обоих устройствах.
- Дополнительные реальные PostgreSQL/коннектор/юридические сценарии: **54 passed**.
- TypeScript, Prettier, production build, Python compile и whitespace checks прошли. Проверены также лимит очереди DNS и тайм-аут с сохранением проверки TLS. Первичная локальная Docker-сборка прошла; финальная повторная сборка остановилась на TLS-тайм-ауте Docker Hub до запуска шагов. Точный выпуск должен пройти Docker gate в CI и сборку на VM до публикации; секреты не входят в контекст.
- npm audit и pip-audit: известных уязвимостей не обнаружено на момент проверки. Replay защит агента: 19/19, это не оценка качества LLM на клиентах.
- Независимое ревью финансов, ограничений ML, tenant/auth и сохранности схемы. Исправлены обнаруженные ошибки, включая неверное устаревание DOCX, скрытый остаток частичного обещания и перенос файла между счетами.

GitHub CI и публикация дополняются после фактического выполнения. Реквизиты юридического лица, корпоративная почта, права и реальные источники не выдумываются.
