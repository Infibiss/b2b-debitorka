## Передача владельцу

По ответу владельца «Пока оставить локально» форма создания Render отменена. В Render подтверждено отсутствие активных сервисов проекта; платный AgentPay не создавался. Файлы Docker/Render и настройка публикации после успешных проверок сохранены, но работающий CD с внешним сервисом пока не проверен.

Локальное приложение: [http://127.0.0.1:8000](http://127.0.0.1:8000). SQLite находится в игнорируемом Git каталоге `server/data/`; приложение запускается с одним worker. Инструкция повторного запуска — в README. Адрес доступен только на компьютере владельца и пока работает процесс сервера.

Корпоративный SMTP и Yandex API с настоящими доступами не вызывались: логика проверена тестами, а реальную доставку и провайдера нужно проверить после подключения. Для работы с шаблонами LLM-ключ и GPU не нужны. Обученного ML-скоринга, прямой синхронизации с 1С/банком и фоновой рассылки в этом выпуске нет.

Владелец отложил реквизиты оператора сервиса. До работы с реальными клиентами нужны эти реквизиты и утвержденные документы, выбранное размещение данных, корпоративная почта и операционная процедура резервного копирования. Подробные границы и порядок запуска описаны в [эксплуатации](operations.md), исследовательские гипотезы — в [обзоре исследования](research/README.md). Цена на сайте — коммерческая гипотеза пилота; готовность клиентов платить и эффект на собираемость пока не подтверждены.
